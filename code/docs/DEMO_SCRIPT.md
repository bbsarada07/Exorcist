# 60-second demo script (UI)

Setup (once): `cd code/ui && npm install && npm run build && npm run preview` → open the printed URL
(or `npm run dev`). Fullscreen the browser. Everything runs offline from `public/data/`.

| Time | Do | Say |
|---|---|---|
| 0:00 | Land on the hero; sweep the mouse through the dark | "Deleted data hides. My cursor is a flashlight — those are masked identifiers still floating in the systems." |
| 0:08 | Click | "Summon." Particles form **EXORCIST**; the headline types; counters run up. "518 requests audited: 355 still haunted, 153 proven, 10 not deletion requests — and 64.2% of the legacy workflow's 'complete' claims were false. Every number comes straight from output.csv and lie_report.json." |
| 0:20 | Scroll to the graveyard; hover a few stones | "Every tombstone is one case. Ember means data still exists, green means deletion proven, the glow is the number of findings, the dashed violet ring is the review queue — guessed links are flagged, not hidden." |
| 0:28 | Press `/`, type `case_483`, press `j` then Enter (or click the stone) | The stone flies into the case header. "A real case: the workflow said **Complete**." |
| 0:34 | Scroll to **Reported vs Reality** | The left side glitches "Complete", the curtain reveals **Haunted**: "False 'complete' — an active data flow, a live search entry, an email still exposed in a support ticket and an open restore path." |
| 0:42 | Click **Perform the Exorcism** | "This animation is driven by the case's actual remediation steps: cut the sync, seal the backup, destroy the search record, black-bar the exposed email. The retained security record keeps its shield — policy says keep it." |
| 0:52 | Watch the ticks cascade and the seal slam (or press Space to skip) | "Every verification check the plan requires turns green — the engine proved this by simulation." |
| 0:56 | Click any runbook step | "And every step can explain itself: rule, policy category, the agent that produced it and the evidence chain." |

Fallbacks: toggle **Lite mode** (top right) on a weak projector — all numbers, labels and steps stay; particles,
grain and shake go. `ctrl/cmd + K` jumps to any case, system or evidence id.
