# 60-second demo script (UI)

Setup (once): `cd code/ui && npm install && npm run build && npm run preview` → open the printed URL. Fullscreen the
browser. Everything runs offline from `public/data/`. Optional: open `#/case/case_483` in a second tab for the
exorcism.

| Time | Do | Say |
|---|---|---|
| 0:00 | Land on the hero; sweep the mouse through the dark | "Deleted data hides. My cursor is a flashlight — those are masked identifiers still floating in the systems. The ink behind it is the audit itself: ember is the share of cases still haunted, green the share proven." |
| 0:08 | Click (or Enter) | Particles form **EXORCIST**, the headline reveals, the odometers roll. "518 requests audited: 355 still haunted, 153 proven, 10 not deletion requests — and 64.2 % of the legacy workflow's 'complete' claims were false. Every number comes from output.csv and lie_report.json." |
| 0:18 | Scroll to the graveyard; hover a few stones | "Every tombstone is one case. The glow is the number of findings, the dashed violet ring is the review queue — 64 guessed links are flagged, not hidden." |
| 0:24 | Press `/`, type `case_483` | Everything else dims, one stone pops with a ring and glides to centre; the strip reads "1 match: case_483 · INCOMPLETE · 4 findings · press Enter to open". Press Enter. |
| 0:30 | The stone flies into the case header; scroll to **Reported vs Reality** | "The workflow said **Complete**. The evidence says **Haunted**: an active data flow, a live search entry, identifiers exposed in a support message and an open restore path." The fluid has turned ember. |
| 0:38 | Click **Perform the Exorcism** | "This animation is the case's actual remediation plan: cut the sync, seal the backup, destroy the search record, black-bar the exposed fields. The retained security record keeps its shield — policy says keep it." |
| 0:50 | Let the checks cascade and the seal slam | **The purge:** green floods out from the seal and pushes the ember to the edges of the screen. "Every verification the plan requires passes — proven by simulation, nothing touched in any real system. Deleted data does not stay dead unless you prove it." |

Fallbacks: on a weak projector use **Perf · Low** or **Lite mode** (top right) — every number, label and step stays;
the fluid becomes a still gradient. If the machine struggles, Auto falls back by itself and offers Lite.
`ctrl/cmd + K` jumps to any case, system or evidence id; Space skips the exorcism to its sealed end state; **Replay**
resets the purge.
